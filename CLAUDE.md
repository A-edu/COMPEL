# CLAUDE.md

All standing project rules live in AGENTS.md so every coding agent follows the same rules. What to build lives in the current sprint spec, `specs/sprint-1.md`.

@AGENTS.md

## Claude Code specifics

- Start each session by reading the **Progress** checklist at the top of the current sprint spec; it tells you what exists.
- When a task names a spec section, read that section plus §2, §3 and §4 of the spec before writing code.
- For any task touching more than a few files, propose a short plan first and wait for approval.
- When you finish a task, tick the Progress checklist, and update the Commands section in AGENTS.md if scripts changed. Do not duplicate project rules in this file.
